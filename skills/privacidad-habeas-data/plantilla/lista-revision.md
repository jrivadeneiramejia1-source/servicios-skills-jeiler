# Lista de revisión de privacidad (antes de entregar)

- [ ] Sé exactamente **qué datos** guarda el sistema y **para qué** (briefing, pregunta 7).
- [ ] No guarda nada que no haga falta; no hay datos sensibles ni de menores.
- [ ] El comprador **acepta antes** de que se guarde algo, y puede **borrar** sus datos.
- [ ] El aviso y la política están adaptados al negocio y dicen que hay servidores fuera de Colombia.
- [ ] Las cuentas (Cloudflare, Meta, Google) están **a nombre del cliente**; ninguna de Jeiler es dueña de sus datos.
- [ ] Las claves son secretos del sistema; ninguna está en un repo, un chat o un papel.
- [ ] Los datos de prueba eran inventados, y se borraron antes de entregar.
- [ ] Jeiler no guardó copias de archivos o datos del cliente (Excel, correos, teléfonos).
- [ ] Si hay archivos contables reales: el dueño dio permiso por escrito para tocarlos y no salieron a servicios externos.
- [ ] Las dudas legales quedaron anotadas para un abogado o la SIC; no se prometió «cumple la ley».
